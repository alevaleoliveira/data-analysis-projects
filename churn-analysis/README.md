# Customer Churn Analysis

## Context
Customer churn is a key metric for subscription-based businesses. Understanding the factors that lead customers to cancel a service helps reduce losses and improve retention strategies.

## Objective
Analyze customer data to identify patterns and factors associated with churn, supporting data-driven business decisions.

## Dataset
The dataset contains customer demographic information, service usage, contract details and churn status.

## Approach
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Identification of key drivers related to churn
